# Integración frontend — Carga masiva (movido)

Este documento se consolidó en **[`INTEGRACION_FRONTEND_CARGA_Y_RESPONSABLE.md`](INTEGRACION_FRONTEND_CARGA_Y_RESPONSABLE.md)**,
que ahora es la guía completa de las tres vías de carga de documentos diligenciados.

El archivo se conserva para no romper enlaces ya repartidos. Lo que estaba acá vive allá, en la
**Vía B · Un admin sube documentos de un momento**: carga masiva, escritura sin aprobación,
corrección de respuestas y la advertencia de sobrescritura.

Se consolidó porque las dos guías describían el mismo flujo de responsable por separado, y la
duplicación ya había empezado a divergir: esta decía que en momentos había que llamar a `aprobar/`
después de asignar y que solo se podían elegir personas existentes, dos cosas que dejaron de ser
ciertas en HU-84 y HU-88.
